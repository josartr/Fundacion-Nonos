# Fundación Nonos

Sitio web estático de la Fundación Nonos, enfocado en reutilización textil, talleres creativos, inclusión y economía circular.

## Contenido

- `index.html`: página principal con propuesta de valor, quiénes somos, proyectos y contacto.
- `historia.html`: relato de origen y recorrido de la fundación.
- `style.css`: estilos del sitio.
- `images/`: recursos visuales usados en ambas páginas.

## Cómo verlo

1. Abre `index.html` en tu navegador.
2. Navega entre secciones desde el menú superior.
3. Usa `historia.html` para ver la historia completa.

## Tecnologías

- HTML5
- CSS3
- Google Fonts
